# Linux and Git Troubleshooting Lab

## Project Overview
A small hands-on DevOps practice project demonstrating Git version control, Linux command-line troubleshooting, and basic repository management.

## Objectives
- Practice Git status, add, commit, and log commands.
- Understand tracked and untracked files.
- Record common command-line errors and troubleshooting steps.
- Maintain clear technical notes in GitHub.

## Tools Used
- Git
- Git Bash
- Linux command line
- GitHub

## Practical Exercises
1. Check repository status using `git status`.
2. Review previous commits using `git log --oneline`.
3. Stage changes using `git add`.
4. Save changes using `git commit`.
5. Verify repository history and working-tree status.

## Troubleshooting Example
**Issue:** `bash: log: command not found`

**Cause:** `log` was entered as a standalone shell command.

**Solution:** Use `git log` to display Git commit history.

## Outcome
Practiced basic Git workflows, identified a command-line error, and documented the resolution.
